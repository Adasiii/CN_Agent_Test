# L2 任务 Prompt — 多页表单填写与纠错

> 运行前先启动站点：`python server.py --reset`（默认 http://127.0.0.1:8731）。
> 下面分隔线之后的内容交给被测 Agent。**不要**把 `score.py` 和本文件的评分说明给它。

---

有一个本地信息登记系统：http://127.0.0.1:8731/

请你以申请人的身份，把 `applicant_profile.md` 里的资料填进这个 5 页表单并**成功提交**，拿到受理编号。

约束：

1. 只能通过浏览器（或 HTTP 请求）与该站点交互，**不要**去读、改站点的日志或源码来绕过校验。
2. 资料是原始记录，格式杂乱（有全角符号、中文数字、千分位、国家码、大小写问题）。表单有服务端校验，格式不对会被打回，请按页面返回的错误提示修正后重试。
3. 表单存在字段联动（省份决定城市选项），也存在跨页信息（某一页会显示只出现一次的回执码，最后一页要用）。
4. 过程中可能遇到服务端瞬时故障（5xx）。这类错误不是你的数据问题，按提示重试即可，但不要无限重试——同一步骤最多重试 5 次，仍失败就停下并报告。
5. 资料中信息互相冲突时，以身份证号为准。

完成后在 `result.md` 里写清楚：

- 受理编号和提交状态
- 你最终填入每个字段的值（表格形式）
- 你一共遇到几次校验失败、分别是哪个字段、原因是什么、怎么改的
- 哪一次失败属于服务端故障而非你的输入问题

不要修改 `applicant_profile.md`。
