# orders_raw 字段说明

数据来自三套业务系统的导出合并，未做任何清洗。`orders_raw.csv` 与 `orders_raw.xlsx` 内容一致，任选其一。

| 字段 | 含义 | 已知问题 |
|---|---|---|
| order_id | 订单号 | 合并时可能整行重复 |
| order_date | 下单日期 | 三套系统日期格式不同；存在非法值和晚于统计截止日的记录 |
| region | 大区 | 中英文、带「区」后缀、前后空格混用；部分缺失 |
| channel | 渠道 | 相对干净 |
| category | 一级品类 | 相对干净 |
| product | 商品名 | 相对干净 |
| customer_id | 客户号 | 相对干净 |
| quantity | 数量 | 存在空值、`NA`、`null`、`-`；存在 0、负数和明显异常的大值 |
| unit_price | 单价(元) | 可能带 `¥`、千分位、前后空格；存在 0 与负数 |
| discount_rate | 折扣率 | 0–0.9 为正常；存在空值与越界值 |
| status | 订单状态 | 已完成 / 已发货 |

统计口径：本次分析的截止日期为 **2026-07-31**。
